# QoL Commands

This mod adds a bunch of handy commands for [Weft](https://github.com/Weft-Rust/Weft). More specifically:

- Homes (up to 8 homes; `/home`, `/sethome`, `/delhome`, `/homes`)
- `/clear` - clear inventory
- `/back` - get back to death place
- `/speed` & `/reach` - increase speed or block reach

## How to install

**Stable Weft** - will be available when Weft 26.11.2 gets released

**Nightly Weft** - clone the repo in `mods/`, run `cargo run --release` to compile both Weft and the mod at once
